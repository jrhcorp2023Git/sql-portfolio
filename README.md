# SQL Portfolio

Hands-on SQL work from a 12-week self-paced SQL refresher, built to keep interview-ready for data, BI, and business systems analyst roles.

All queries run in SQLite (DB Browser for SQLite) against a small sample sales database of customers, products, orders, and order items. The data is made up.

## How to run
1. Install [DB Browser for SQLite](https://sqlitebrowser.org/) (free).
2. Create a new database and run `data/practice.sql` to build the tables.
3. Open any week's `solutions.sql` and run the queries.
